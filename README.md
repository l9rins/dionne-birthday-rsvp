# Dionne Birthday RSVP

A single-page birthday RSVP site for Dionne Margaret. The project is a simple static site made from one HTML file and a folder of photos.

## What's inside

- `dionne-rsvp.html` - the main invitation and RSVP page
- `dionne-pics/` - image assets used by the page

## How to use

Open `dionne-rsvp.html` in a web browser to view the invitation locally.

If you want to share it online, upload the HTML file and the `dionne-pics/` folder together so the image paths continue to work.

## Notes

- The page is static and does not require a build step.
- External fonts are loaded from Google Fonts.
