## 🚀 Overview

**Dionne Birthday RSVP** is a beautifully simple, single-page static site created to invite friends and family to Dionne Margaret's birthday celebration. It features a straightforward RSVP interface alongside a personalized folder of photos.

Whether you're viewing it locally or hosting it online, this project is designed to be lightweight, easy to deploy, and fully static—no build steps required!

> "A special invitation for a special day."

---

## ✨ Features

*   **Zero Dependencies:** A pure static site made from just one HTML file and a folder of photos.
*   **Easy Deployment:** Simply upload the HTML file and the image directory to any web host, and it works instantly.
*   **Photo Integration:** Seamlessly displays image assets from the `dionne-pics/` folder.
*   **No Build Step:** Forget complex setups—just open in your browser and you're good to go.

## 🚀 How to Use

1.  **Local Viewing:** Open `dionne-rsvp.html` in any modern web browser to view the invitation locally.
2.  **Online Hosting:** If you want to share it online, upload the `dionne-rsvp.html` file and the entire `dionne-pics/` folder together to your preferred web host to ensure all image paths continue to work seamlessly.
